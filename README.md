# Cálculo de desconto do INSS

Programa de console em C# feito como exercício para praticar estruturas condicionais (`if` e `else`).

## O que o programa faz

Solicita ao usuário o valor do salário e calcula o desconto conforme estas regras do exercício:

- Salário de até R$ 1.000,00: desconto de 8%.
- Salário acima de R$ 1.000,00: desconto de 10%.

Ao final, mostra o valor calculado para o desconto.

> Este programa é um exercício didático e usa regras simplificadas. Não representa necessariamente o cálculo oficial do INSS.

## Tecnologias

- C#
- .NET
